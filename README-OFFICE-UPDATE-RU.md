# AIOffice — пиксельный офис (экспериментальная версия)

Добавлено: офис с видом сверху и кликабельными сотрудниками, всплывающие индикаторы одобрений, рабочий компьютер агента, перемещение свободных персонажей (визуальное), пауза сценариста с сохранением настройки, запуск локального ComfyUI в фоне по указанному пользователем .bat/.exe.

## Настройка ComfyUI
Откройте «Настройки», укажите абсолютный путь к **файлу запуска** установленного ComfyUI и включите «Автоматически запускать». Пример для portable-версии: `C:\ComfyUI_windows_portable\run_nvidia_gpu.bat`. Для Desktop путь может отличаться; если нет отдельного исполняемого файла для фонового сервера, настройку нельзя использовать без подготовки запуска. Приложение не скачивает и не устанавливает ComfyUI самостоятельно. Сервер ожидается на `http://127.0.0.1:8188`.

## Ограничения
Это обновление интерфейса и управления. **Pika H3 Flex пока не интегрирован в автоматический монтаж**: нужен экспорт API JSON рабочего графа из ComfyUI. Существующий монтажёр изображений остаётся без изменений. «Гуляние» агентов — декоративная анимация статусов, а не физическая симуляция. HR и добавление новых агентов пока не реализованы. Остановка сценариста не прерывает уже отправленный запрос Claude, но блокирует следующий цикл.
