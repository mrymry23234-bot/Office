# AIOffice — экспериментальный послойный монтаж

В настройках выберите «Раздельные фон и персонаж (экспериментальный)» и сохраните.

Монтажёр генерирует через локальный ComfyUI две картинки на сцену: `visuals/<id>/<scene>_background.png` и `..._actor.png`. Персонаж создаётся на зелёном фоне, который удаляется простым chroma-key, затем персонаж независимо от фона плавно перемещается и наклоняется. Это НЕ полноценная скелетная анимация: руки и ноги отдельно пока не двигаются, моргание не реализовано. Нейросеть может нарисовать лишние конечности; текстовый запрос снижает вероятность, но не гарантирует анатомию.

Если персонаж не отделяется от фона, монтаж остановится с понятной ошибкой, сценарий сохранится. Для повторной генерации проблемной сцены удалите только соответствующий файл `_actor.png` из папки `visuals/<id>/` и нажмите «Повторить монтаж». Существующие данные `office.db`, `settings.json`, `token.json`, `client_secret.json` не перезаписывайте и не загружайте в публичный GitHub.

Ограничения: при сложном фоне, зелёной одежде или шерсти простой chroma-key может давать артефакты. На один ролик понадобится примерно вдвое больше генераций изображений. Режим не тестировался на Windows с реальным ComfyUI; перед использованием сделайте резервную копию.
