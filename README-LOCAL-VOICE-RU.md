# AIOffice: локальная озвучка — экспериментальное обновление

## Установка
1. Скачайте Windows-версию Piper TTS из официального репозитория rhasspy/piper и распакуйте её на компьютере.
2. Скачайте голосовые модели русского и английского языков: для каждого голоса нужны **два файла**: `.onnx` и `.onnx.json`. Модели в ZIP AIOffice **не включены**.
3. Положите модели в папку `voices` рядом с AIOffice.exe либо укажите абсолютный путь к папке в настройках.
4. В настройках AIOffice укажите путь к `piper.exe` и папке голосов, сохраните настройки. Выберите голос из списка и нажмите «Проверить локальный голос».
5. При монтаже программа создаёт WAV локально, а затем соединяет его с видеорядом. Интернет для озвучки не нужен, но сценарист Claude и другие сетевые функции по-прежнему требуют интернет.

## Архив
В интерфейсе «Архив видео и переозвучка» выберите существующий MP4, введите **готовый переведённый текст**, нажмите «Создать новую озвучку». Исходный MP4 не изменяется, новая версия появится на утверждении. Автоматический перевод пока не реализован. Переозвучка использует исходный видеоряд без перестройки сцен; длительность нового голоса может не совпасть с исходной, поэтому результат нужно просмотреть перед публикацией. Субтитры в видеокадрах не заменяются автоматически.

## Ограничения
- Для каждого языка нужно отдельно установить голосовую модель.
- Запуск Piper и реальный синтез речи на Windows ещё не проверены на компьютере пользователя.
- Многоканальный YouTube OAuth и выбор канала публикации **не реализованы**. Не подключайте несколько каналов до появления отдельного подтверждения канала перед публикацией.
- Существующий запуск ComfyUI в фоне остаётся прежним и зависит от настроенного пути и флажка автозапуска; гарантированным он не стал.
- Не удаляйте папку videos или office.db без резервной копии.
