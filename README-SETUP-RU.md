# AIOffice: локальные AI-иллюстрации (RTX 4060 / 16 ГБ RAM)

## Что реализовано
- Сценарий → генерация отдельных иллюстраций по сценам через локальный ComfyUI → панорама/субтитры/озвучка → MP4.
- Изображения кэшируются в `visuals/<номер задания>/`: повторный монтаж использует готовые кадры.
- При ошибке генератора сценарий остаётся в статусе ошибки, можно повторить или удалить.
- В настройках выбирается модель, адрес сервера и число шагов.

## Однократная установка на Windows
1. Скачайте официальную **ComfyUI Desktop** с https://www.comfy.org/download и установите с поддержкой NVIDIA GPU.
2. Установите совместимую модель Stable Diffusion checkpoint (например, SD 1.5 cartoon / DreamShaper, с проверенной лицензией) в папку `ComfyUI/models/checkpoints` вашей установки. Модель не входит в архив, поскольку она занимает гигабайты и имеет отдельную лицензию.
3. Запустите ComfyUI и убедитесь, что он доступен по `http://127.0.0.1:8188` (у Desktop порт может отличаться; проверьте в настройках).
4. Запустите AIOffice, выберите `AI-иллюстрации через ComfyUI`, укажите адрес, сохраните настройки и нажмите `Проверить генератор изображений`.
5. Если проверка успешна, повторите монтаж сохранённого сценария.

## Важно
- Claude API не генерирует изображения. Генерация ComfyUI локальная, без платы за изображения, но потребляет GPU и электричество.
- Это **генерация отдельных статичных кадров**, а не полноценная text-to-video анимация персонажей. В текущем обновлении монтаж выполняет панорамирование и субтитры. Настоящая анимация персонажей потребует отдельной модели/движка и тестирования на RTX 4060.
- Для работы ComfyUI должен быть запущен. GitHub Actions собирает AIOffice, но не устанавливает модель на компьютер.
- Сохраните резервную копию `office.db` и `settings.json` перед заменой приложения.
- Для лучшей согласованности героев нужен reference-image / IP-Adapter workflow, пока не реализован.
- Не публикуйте `settings.json`, `office.db`, `token.json` или API-ключи в GitHub.
