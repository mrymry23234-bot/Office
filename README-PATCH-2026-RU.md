# Обновление для SDXL Turbo

- При выбранной SDXL Turbo используются 1–4 шага, CFG 1 и sampler euler_ancestral. По умолчанию 2 шага.
- Если checkpoint не задан, приоритет у установленной SDXL Turbo.
- Повреждённые изображения автоматически перегенерируются.
- При удалении неудавшегося сценария очищаются также его сгенерированные иллюстрации.
- Сохранены восстановление сценариев и повторный монтаж из предыдущей версии.

ВАЖНО: Это исправление генерации *изображений*, не система полноценной анимации персонажей. При монтаже остаются движения камеры по статичным изображениям.

Для Windows загрузите исходники в GitHub, соберите Actions. Сохраните копии office.db, settings.json, token.json и client_secret.json перед заменой. Не размещайте ключи и токены в публичном репозитории.
