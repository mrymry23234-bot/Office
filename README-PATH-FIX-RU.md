# Исправление поиска графа озвучки

Монтажёр сначала ищет `voice_workflow_api.json` рядом с `AIOffice.exe`, затем — во встроенных ресурсах PyInstaller. В сообщении об ошибке выводятся оба проверенных пути.

Соберите новую версию через GitHub Actions, заменив файлы проекта из архива. Перед заменой сохраните `office.db` и `settings.json`. Не проверено на Windows в этой среде.
