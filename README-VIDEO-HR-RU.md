# AIOffice — Pixel Office + локальное видео + HR (экспериментальная сборка)

## Что реализовано
- В офисе 12 мест (4 колонки × 3 ряда), 4 штатных сотрудника (включая HR) и места для новых.
- HR создаёт дополнительных агентов с именем и постоянными обязанностями. Можно выдавать им текстовые задания и читать результаты в их компьютерах. Их работа использует уже настроенный Claude API. Агенты пока НЕ имеют доступа к файлам, браузеру, YouTube или ComfyUI и не могут самостоятельно выполнять произвольные действия.
- Новый режим «Локальная генерация ВИДЕО через ComfyUI» заменяет отрисовку изображений на получение коротких видеофрагментов от ComfyUI, приводит их к вертикальному формату, собирает с озвучкой.
- Повторный монтаж сохраняет сценарии при ошибках, как и раньше. Пауза сценариста сохранена.
- ComfyUI можно запускать фоном, указав путь к локальному файлу запуска и включив автозапуск.

## ВАЖНО: один раз импортировать рабочий API workflow
1. В ComfyUI откройте именно работающий Pika H3 Flex граф.
2. Экспортируйте его как **API Format JSON** (в зависимости от версии через меню Save (API Format) / Dev Mode). Обычный workflow JSON, где узлы находятся в массиве `nodes`, НЕ подходит.
3. В AIOffice -> Настройки -> «API JSON рабочего графа Pika H3 Flex» выберите экспортированный файл.
4. Укажите ID узла и имя текстового поля промпта, если автопоиск не найдёт единственный текстовый промпт. В JSON это `"12": {"class_type":"...", "inputs":{"prompt":"..."}}` => ID `12`, поле `prompt`.
5. Выберите режим локальной генерации ВИДЕО, включите фоновый запуск ComfyUI, сохраните настройки.
6. Убедитесь, что граф содержит сохраняющий видео узел и ComfyUI отдаёт файл через `/history` -> `/view`.

**Необязательно повторно загружать граф** после каждого запуска: он сохраняется в `video_workflow_api.json` рядом с AIOffice. Веса Pika H3 Flex уже установленные в ComfyUI не копируются в архив.

## Ограничения
- Интеграция проверена статически (Python и JS), но не запускалась с Pika H3 Flex и RTX 4060: API структура и имена входов могут отличаться. Некоторые графы сохраняют видео нестандартным способом; в таком случае понадобится адаптация к конкретному API JSON.
- Генерация видеосцен идёт последовательно; если модель не помещается в VRAM/RAM, ComfyUI может завершиться ошибкой. Встроенный рендер не исправляет дефекты анатомии.
- Текущий голос edge-tts требует интернет, поэтому весь конвейер пока не полностью офлайн; локальна именно генерация видео. Claude API также остаётся внешним.
- HR нанимает текстовых агентов. Для агентов с реальными действиями нужны отдельные безопасные инструменты и разрешения.
- Сохраняйте резервную копию `office.db`, `settings.json`, `videos/` и `token.json` перед обновлением. Не публикуйте ключи и токены в GitHub.
