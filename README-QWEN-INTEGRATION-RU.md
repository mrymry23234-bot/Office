# Qwen3-TTS в AIOffice

Озвучка теперь использует установленный ComfyUI и API-граф `voice_workflow_api.json` (экспорт пользователя). Не нужен Piper.

1. Запустите ComfyUI Desktop и убедитесь, что он доступен на http://127.0.0.1:8188.
2. Запустите AIOffice; в настройках выберите «Qwen3-TTS (через ComfyUI)», модель 0.6B и голос Ryan. Нажмите «Сохранить».
3. Нажмите «Проверить локальный голос». Проверка и монтаж используют одинаковый механизм.
4. Видеоредактор автоматически получает WAV, сконвертированный из FLAC через встроенный ffmpeg. Переозвучка архива тоже использует Qwen3-TTS.

Внимание: автозапуск ComfyUI требует правильно настроенного `comfy_launch_command` и не проверен на вашем ПК. Если ComfyUI Desktop уже запущен, AIOffice использует его без дополнительного запуска.

При изменении версии ComfyUI или модели проверьте голос отдельно. 1.7B потребляет больше памяти и может конкурировать с видеогенерацией.
