# AIOffice: исправление сохранения сценария при ошибке

- При ошибке монтажа сценарий сохраняется в office.db и показывается в интерфейсе с текстом ошибки.
- Кнопка «Повторить монтаж» повторно запускает тот же сценарий без обращения к сценаристу.
- После аварийного завершения незавершённый статус rendering восстанавливается в render_failed при следующем запуске.
- Исправлена видимость ошибок монтажа в интерфейсе.

ВАЖНО: это исправление не генерирует изображения. Режим «Иллюстрации» по-прежнему требует visuals/<ID>/<номер_сцены>.png. Автоматическая локальная генерация через ComfyUI должна быть подключена отдельно.

ВАЖНО: не удаляйте office.db и settings.json при обновлении программы. В них находятся сценарии и настройки. Сделайте резервную копию перед обновлением.
