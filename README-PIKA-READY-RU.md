# AIOffice: встроен ваш API workflow Pika H3 Flex

В эту сборку включён присланный вами файл `video_pika_h3_flex_t2v.json` как `video_workflow_api.json`. Повторно экспортировать или импортировать граф не нужно.

1. Сделайте резервную копию данных AIOffice (office.db, settings.json, videos/, token.json).
2. Соберите Windows-версию из исходников через GitHub Actions.
3. В настройках выберите «Локальная генерация ВИДЕО через ComfyUI».
4. Проверьте адрес ComfyUI (по умолчанию http://127.0.0.1:8188), настройте фоновый запуск при необходимости.
5. Узел промпта: `140:131`; поле: `prompt`.
6. Для первого теста одобрите короткий сценарий, проверьте получение видео.

ВНИМАНИЕ: граф содержит тяжёлые модели и может не поместиться в RTX 4060 8 ГБ / RAM 16 ГБ. Встроенный граф использует 9:16, 0.1 megapixels и 5 секунд на сцену. Код не тестировался с реальным ComfyUI в этой среде. Озвучка через edge-tts и Claude API остаются сетевыми.

Если видео не обнаруживается в истории ComfyUI, потребуется адаптировать получение результата SaveVideo под установленную версию.
