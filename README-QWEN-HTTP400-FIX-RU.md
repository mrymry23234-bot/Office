# Исправление Qwen3-TTS / HTTP 400

В рабочем `voice_workflow_api.json` узел `FB_Qwen3TTSCustomVoice` использует модель `1.7B`. Раньше AIOffice всегда заменял её на значение из `settings.json` (по умолчанию `0.6B`). Теперь модель берётся из экспортированного workflow. Другие параметры узла, включая язык, остаются из JSON; текст, голос и seed подставляются для каждого задания.

При HTTP 400 теперь показывается тело ответа ComfyUI с ошибками узлов, а не только `Bad Request`. Это позволяет диагностировать другие причины несовместимости.

**Проверка:** закройте прежний EXE, соберите новый через GitHub Actions, замените EXE, сохраните рядом `voice_workflow_api.json`, запустите ComfyUI Desktop и нажмите «Проверить локальный голос». Если ошибка останется, скопируйте её полный текст.

Исправление проверено синтаксически; реальный ComfyUI на вашем Windows здесь недоступен, поэтому успешная генерация из новой сборки не подтверждена.
