# Исправление сборки Qwen3-TTS

В исходном архиве интерфейс Qwen3-TTS уже реализован, но GitHub Actions не включал `voice_workflow_api.json` в exe. Это исправлено в обоих файлах сборки (`build.yml` и `.github/workflows/build.yml`). Также включены `video_workflow_api.json` и `font.ttf`.

## Как получить новую программу

1. Замените файлы проекта в GitHub содержимым этого архива, сохранив структуру каталогов.
2. Откройте GitHub → Actions → Build AI Office → Run workflow.
3. Скачайте свежий артефакт `AIOffice-Windows` и запустите его вместо старого exe.
4. Закройте старую программу перед запуском (порт 8000 должен быть свободен).
5. В настройках выберите `Qwen3-TTS (через ComfyUI)`, модель `0.6B`, голос `Ryan`, сохраните и нажмите «Проверить локальный голос».
6. ComfyUI Desktop должен быть запущен на `http://127.0.0.1:8188`.

**Важно:** Это исправление упаковки; запуск exe на вашем Windows ПК здесь не проверялся. Настройки и база сохраняются в текущей рабочей папке приложения; сохраните резервные копии `settings.json` и `office.db` перед заменой.
