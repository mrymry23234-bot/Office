# AIOffice — первая техническая доработка

Это промежуточная версия, **не готовый автоматический AI-монтажёр**.

## Изменения
- В настройках добавлены отдельные правила аналитика.
- Добавлен режим «Иллюстрации»: он не вызывает Claude для рисования фигур.
- В режиме иллюстраций используются готовые PNG/JPG/WebP, плавные панорамы, озвучка и субтитры.
- Старый режим оставлен для совместимости.

## Как работают иллюстрации
После утверждения сценария монтажёр создаёт ролик с ID из базы данных. Для каждой сцены ему нужен файл `visuals/<ID>/1.png`, `visuals/<ID>/2.png` и т. д. Допустимы `.jpg`, `.jpeg`, `.webp`. Если изображений нет, монтаж останавливается с понятной ошибкой — **не заменяет изображения Paint-фигурами**.

**Ограничение:** пока нет автоматического создания изображений, анимации персонажей, локального ComfyUI и автоматической загрузки визуалов. Следующий этап — подключение локального ComfyUI (RTX 4060 8 ГБ) с очередью и кэшем изображений, затем монтаж по раскадровке. Текущий режим не пригоден для полностью автоматического выпуска роликов без предварительной подготовки картинок.

## GitHub
Замените файлы в репозитории содержимым этого архива. Workflow `.github/workflows/build.yml` сохранён. GitHub Actions соберёт EXE, но генерация изображений локально на компьютере потребует отдельной установки моделей/движка и не произойдёт на GitHub runner автоматически.

Не добавляйте в GitHub `settings.json`, API-ключи, `token.json`, `client_secret.json`.
